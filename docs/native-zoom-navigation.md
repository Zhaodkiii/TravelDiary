# 原生缩放转场

内容卡片进入详情时使用系统 Zoom Transition，返回时收回打开它的卡片。普通功能导航继续使用原有转场。

## 根导航结构

四个 Tab 共用外层 `rootNavigation(path: $path)`，内部是单个 `TabView`。详情页推入外层栈，自然覆盖包含 Tab 栏的根页面，返回根页面时重新显示 Tab 栏。

- 手帐、素材、定制、设置共用一个 `NavigationPath`，不再分别保存各 Tab 的详情栈。
- `DiaryBookRoute`、`CustomizationRoute`、`SupportRoute`、`AccountRoute` 在外层栈根部统一注册。
- 反馈和定制通知先选择所属 Tab，再替换共享路径。返回时显示对应的 Tab 首页。
- 普通页面直接使用 `NavigationLink`；不再使用 Tab 栏显隐扩展或 `.toolbar(..., for: .tabBar)`。
- 根页面标题和头部按钮均由 `SupportMainCoordinatorView` 的 `currentTabTitle` / `tabToolbar` 管理，挂在外层栈内的 Tab 容器上。
- 手帐：新建手帐。素材：按当前模板 / 相册 / 贴纸 / 字体分类显示搜索；模板和相册显示筛选；所有素材分类显示“我的素材”菜单。定制：提醒设置。设置：首页没有额外头部按钮。
- `DiaryMaterialToolbarState` 同步素材分类、目录和筛选状态；筛选请求按内容类型发送，由对应素材页消费一次并展示筛选面板。独立打开的素材系列、搜索及选择模板页面保留自身工具栏。
- 详情页继续管理自己的标题和操作，首页工具栏不迁移到详情。

## 已接入的入口

| 来源 | 目标 |
| --- | --- |
| 我的手帐中的封面卡片 | 手帐阅读页 |
| 模板 / 相册素材卡片、整本搜索结果 | 模板详情 |
| 本机与云端模板详情中的跨页缩略图 | 全屏页面预览 |
| 贴纸包卡片 | 贴纸包详情 |
| 单张贴纸列表、首页推荐、贴纸包内缩略图 | 单张贴纸预览 |
| 贴纸包展示图 | 大图预览 |
| 字体卡片 | 字体详情 |

## 接入规则

- 卡片导航复用 `ZoomNavigationLink`，每个入口拥有独立的 Namespace，避免同一素材在不同列表出现时匹配到错误的来源。
- 基于路由或弹窗的入口使用 `contentZoomSource` 和 `contentZoomTransition`，双方的 ID 类型、值与 Namespace 必须一致。
- 书架路由仅在封面点击时设置 `zoomFromShelf`。通知、新建完成、管理页面等入口没有对应的封面来源，保留普通导航。
- 全屏模板预览翻页后仍收回最初打开的跨页缩略图。
- 开启系统“减少动态效果”后不应用 Zoom Transition。
- 登录、设置层级、新建步骤、导入、支付、相机和编辑器保留原有导航及关闭行为。

## 交互验收

1. 从以上每种卡片打开目标，检查展开位置和返回的来源是否一致。
2. 测试返回按钮、系统交互式返回，以及拖动一半后取消；来源卡片应重新显示并可再次打开。
3. 在同一素材的不同入口、多层详情和重复打开场景中检查来源匹配。
4. 模板全屏预览翻页后关闭，再测试“使用这一页”，确认先结束预览再出现导入面板。
5. 测试贴纸预览的收藏、使用与选择手帐流程，确认已有关闭后回调继续执行。
6. 从四个 Tab 进入详情，确认详情没有底部 Tab 栏；返回根页面后显示原来选中的 Tab，并在开启“减少动态效果”后重复操作。
7. 在详情页收到反馈 / 定制通知时，检查共享栈切到通知目标，返回后显示通知所属 Tab；检查账号管理入口及新建完成后的手帐跳转。
8. 从书架切换到素材、定制和设置，检查根导航标题和该 Tab 的操作；详情页应使用自己的标题和工具栏。
9. 素材页分别点击和滑动切换四个分类，检查搜索入口、模板 / 相册的筛选按钮及选中状态；筛选面板应只出现一次，分类之间互不影响。检查“我的素材”的三个入口和定制提醒设置。

编译检查不能替代以上设备交互验收。
