# 照片与相框持久化合成

保存页面（包括批量替换照片）后，以 1800 像素素材生成透明合成图。资源位于作品资源根目录的 `derived/photo-composites/<SHA256>.png`。读取旧作品的大图预览时按需补齐；缩略图不会以低分辨率覆盖这些资源。

指纹包含照片和绑定相框的完整局部图层参数、不可变素材 ID、渲染版本和分辨率。外层摆放变换归零，因此平移、旋转、翻转、透视无需重新烘焙。裁剪、透明度、照片替换、相框样式等变化产生不同资源。文件原子写入，旧资源保留供撤销和历史页面复用；删除作品时随目录删除。

只有连续排列、普通混合模式的照片及其可见绑定相框会合成。跨图层遮挡和背景相关混合效果保留原路径。原始可编辑文档、素材和高清导出路径不变。阅读器接收临时派生文档：照片 ID、变换、动画语义保留，相框被合入照片贴图，动画按同一个 ID 播放。

缓存缺失、损坏或写入失败不会使保存失败；阅读可以重新生成或使用本次内存结果。持久化图片用于阅读分辨率，高清导出始终使用原始素材。旧版本派生资源目前随作品保留，不进行逐版本淘汰。

验证：DiaryPhotoCompositeTests 覆盖保存落盘、读取复用、摆放复用、内容变化失效、损坏恢复及原文档不变；回归 DiaryPhotoFrameTests、DiaryReadingAnimationTests。
