# Debug 手帐导入

Debug 构建 → 手帐书架 → 右上角下载图标「Debug 导入」→ 从「文件」选择 ZIP 或完整项目文件夹。

电脑 Downloads 的文件需要先 AirDrop 到设备文件 App。ZIP 支持根目录直接包含 book.json，也支持外包一层项目文件夹。目录必须只有一个 book.json；保留 pages、assets 及派生资源目录。

按 book.id 匹配当前账号的书架。存在时完整替换为选中文件版本，不合并、不比较外部时间戳；不存在则创建。选中的导入版本视为最新版本。旧目录在新目录发布成功后才删除；校验失败不改原作品。

校验当前页面及最近删除页面的 manifest、对象、绘画、素材可解码性；ZIP 拒绝符号链接和父目录跳转，解压体积上限 2 GB。导入成功刷新书架、阅读素材内存缓存及本书预览缓存。入口和导入方法仅在 DEBUG 下编译。

外部手工新增修订时，manifest 中的对象 path/drawingPath 也必须指向新修订，Date 使用 Swift Codable 的 2001 年时间基准。
