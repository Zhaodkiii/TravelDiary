# 手帐封面流程

- 封面由 coverPageID 明确指定，不回退到正文第一页。
- 新封面画布固定为 2185 × 3130；横向、正方形页不能设为封面。
- 封面固定在目录首位，阅读首屏左侧为衬底，右侧为封面；缺失时提供添加入口。
- coverDraft 独立保存，可退出继续制作，不进入正文、书架封面或成品导出。
- 完成编辑后才发布封面；空白退出删除草稿引用。
- 替换、移除封面将旧封面移入最近删除；恢复不会自动设置封面。
- 正文竖版页可复制为封面；完整配对的模板页只能复制，避免拆散配对。
- 封面不占正文页码，跨页正文按两页计数；默认正文画布尺寸独立保存。
- 无封面时成品导出跳过封面占位；源文件包含草稿以保留可编辑状态。
