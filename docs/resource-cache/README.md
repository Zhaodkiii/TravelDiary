# 公共资源缓存与冷启动验收

## 公共入口

- `CatalogResponseCache.load`：账号＋环境 URL＋规范化查询参数隔离；默认新鲜期 5 分钟、可展示期 7 天。只读参考内容可使用 `.reference`（1 小时／30 天）。`onCached` 必须直接更新页面，不能等最终返回才显示；`onPhase` 可接收 loading/cached/refreshing/ready/offline/failed。
- `PreviewImagePipeline.load`：内存 → 按尺寸生成的磁盘小图 → 已下载本地文件／磁盘原始字节 → 网络。图片身份采用内容 SHA 或资源 ID＋版本，签名 URL 不作为身份。默认下载最多并发 4 个，相同身份合并请求。
- `PreviewImageRequest`：业务声明账号范围、稳定标识、像素尺寸、可选 SHA、URL 校验、大小限制及签名刷新回调。URL 为 nil 时，仅在缓存缺失后调用刷新回调取得下载地址。
- `ResourceCache`：统一磁盘预算；目录在不超过 min(16MB, 总容量10%) 时优先于其他数据保留，仍受总上限约束，不是永久保护。小图与原图同分类，清理会同时移除。
- `ResourceLoadMetrics`：最多 512 条内存事件，同时发到系统日志 TravelDiary / ResourceCache。只输出分类、标识摘要、阶段、耗时、字节数，不记录 URL、令牌或正文。

## 接入范围

贴纸封面（512px）、单张缩略图（384px）、字体列表（384px）和字体详情（1024px）、预设图片、个人贴纸预览、帮助文章插图共用图片管线。远程图片小于等于 1024px 的规格生成 PNG 磁盘衍生图，保留透明度。大图按需解码，不生成此类衍生图。

贴纸首屏最多预热 8 张封面，低优先级顺序执行；不作为 App 启动依赖。新模块可调用同一 `prefetch`，不要启动时全量预热。

贴纸主题、预设搜索、个人贴纸及帮助列表接入旧缓存立即展示。字体列表原有 onCached 保留。预设主目录保留已有本地快照恢复机制。本地手帐／相册保留专用渲染及存储，接入公共耗时记录，手帐磁盘预览解码移到后台。

收藏仅标记目录需要刷新并保留快照；分页游标失效不再清空整个贴纸目录。权限／领取等变化继续硬失效。个人贴纸创建、删除后硬失效私有列表；删除同时清除该账号的个人贴纸预览缓存。

原始照片、手帐正文、未上传草稿、个人贴纸原件、已下载字体及离线素材包不纳入可淘汰预览缓存。支付、订单、会员权益、下载授权不套用旧目录快照作为决策依据。行政区划保留原有内置兜底与版本机制。

## 诊断

`ResourceLoadMetrics.shared.snapshot()` 可在调试器或测试中读取最近事件。系统日志可筛选 subsystem=TravelDiary, category=ResourceCache。

- `catalog.disk.hit / catalog.miss / catalog.expired / catalog.coalesced / catalog.offline`
- `disk.hit / disk.miss / disk.read.failed`
- `image.memory.hit / image.rendition.hit / image.corrupt / image.queue / image.decode / image.download / image.download.retry`
- `write.success / write.rejected / write.capacity / write.failed`
- `catalog.load.finished / image.load.finished`（包括失败时的总耗时，不等同于屏幕实际绘制完成）

图片 download 事件统计收到的响应体字节，包含 HTTP 失败及重试响应；不包含协议头。catalog.fetch 的字节是引擎交付的响应体，304 合并后是本地正文大小，不能当作真实网络流量。判断目录网络传输需结合网络引擎的 200/304 日志。

## 自动化验证

运行 `python3 scripts/test_resource_cache.py`。脚本只编译并运行缓存、存储和预设相关回归测试，避免既有无关测试编译问题。

覆盖：磁盘跨实例重启、签名 URL 改变仍命中、内容版本改变重新加载、原图淘汰后小图仍可用、分类清理同时删除小图、账号隔离、下载中清理拒绝晚写入、并发去重、非法图片不落盘、目录过期／离线／403、软失效后缓存仍立即返回、目录优先保留及容量约束。

## 真机验收

1. 登录固定账号，浏览贴纸、预设、字体、个人贴纸、帮助内容；等待首屏加载完成。
2. 杀进程、断网，再启动并访问相同页面。已缓存内容应可见，图片下载字节为零；目录缓存失效或设备清理过的内容允许缺失。
3. 联网刷新，已有内容不清空；新版本替换旧数据。检查首次展示耗时及图片解码耗时。
4. 收藏后重启，旧目录可立即显示，联网后收藏状态更新；删除个人贴纸后重启，已删除项目不可从旧列表恢复。
5. 切换账号，个人贴纸和字体账号状态不能串号。清理缓存后允许重新下载，但本地手帐和离线下载包仍在。
6. 对比同一台设备相同页面至少 10 次冷启动，记录 P50/P95；以真机结果设性能门槛，不以模拟器数据宣称秒开。

自动化测试不替代真实账号、真机断网冷启动及最终视觉验收。
