# 分类故事输入

2026-11-04

入口在 AI 制作页底部。“写点故事”打开轻量输入面板并请求键盘焦点，默认内容；可切换标题、制作方向、地点。添加保留键盘，完成提交当前非空内容并关闭。下滑关闭保留未提交文字。标题和地点单例更新，内容和方向允许多条。标签可编辑、删除，在底部操作栏单行横向滚动；不单独占用上方内容空间，右侧制作按钮固定。

CreationBrief 的可选 storyEntries / storyInputDrafts 沿用页面 AI 表单持久化；旧 JSON 无新增字段仍能解码。输入不发起模型请求，开始制作冻结请求。运行期间禁用故事编辑；暂停或完成后修改标签，主操作变为按新故事重新制作。重新制作清理当前页未锁定且带故事来源的文字，不清理手工文字或其他页。

分类资料传入已有构图、文字和背景流程。制作方向不印作正文，原样内容完整呈现，参考地点和参考内容不能直接印出。生成背景不得绘制文字。原生文字图层保存 storySourceID；模型使用 story-UUID 作为 clientObjectKey。提交文字批次时检查必需原文是否完整存在，缺失返回可修复错误。可润色内容的语义忠实和视觉方向仍依赖模型及已有视觉检查，不能用字符串检查保证。

验证：新增 DiaryStoryEntryTests 覆盖标题单例与稳定 ID、空输入、多个正文、草稿编解码与旧字段兼容、地点隐私、标题原样约束和漏字阻断。常规测试目标受到现有 Networking/OSS 等测试编译错误阻断；定向测试临时排除其他测试源文件并补 CoreTelephony / SystemConfiguration 链接参数，不修改项目设置。3 项定向测试全部通过（TEST SUCCEEDED）。

尚需设备验收：小屏及大字体下键盘和输入面板布局、中文输入法组合输入、真实 AI 输出效果。没有在本次验证中调用收费模型。
