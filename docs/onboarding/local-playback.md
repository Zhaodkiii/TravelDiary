# 启动引导的手帐装订

## 页面设计

保留奶油白底、黄色品牌标识、深色主按钮和风格选择流程。前三屏是同一本六页样册：龙龛与洱海湖岸、喜洲古镇、周城扎染。

每个未装订跨页采用相同流程：

1. 纸页只显示模板背景，停留 450 ms。
2. 真实照片与纸片在书页上方错落展开，保持倾斜和悬浮阴影。主按钮为“装订这一页”；页内文字和下方引导文案均隐藏。
3. 点击装订，照片先落入真实模板位置，装饰延后 180 ms。整段落纸预算 1.35 s，阴影随贴合消失。
4. 落纸完成后，页内文字用 480 ms 淡入；随后显示下方引导文案，按钮变为“下一步”。
5. 下一步复用原生卷页。皮革外壳位置固定，目标页在卷动期间只显示背景；翻页结束后从步骤 1 开始下一组素材。

装订和翻页期间禁用重复操作，跳过仍可用。返回已装订跨页直接恢复成品；进入风格选择再返回时同样保留状态。未装订时允许返回上一页，之后重新进入该页会重新展开素材。引导中由按钮控制翻页，避免滑动绕过装订流程。

减少动态效果时仍保留“点击装订”的交互步骤，取消位移、倾斜过渡、等待和卷页动画。模板载入失败时使用随包成品图兜底，允许继续和跳过。

## 资源来源

大理·把日子过成蓝白色，模板 ID 88a7b289-2c50-49cc-8b53-742e1dcd4360，已发布版本 4。
本地包为 `TravelDiaryClient/Projects/App/Resources/OnboardingDali.bundle`，按 manifest.json 的三个阅读单元加载六页，对应原书第 2/3、8/9、16/17 页。不依赖网络，也不保存 OSS 凭据或临时签名链接。

## 实现

- `DiaryOnboardingAssembly` 持有加载、空白、悬浮、装订、文字显现、完成、翻页、失败状态。异步任务带取消与代次检查，重复装订调用不重复启动动画。
- `DiaryPresetPackage.instantiate` 创建临时内存文档。使用现有 `DiaryPageRenderer` 输出每页背景、无文字成品、完整成品，以及照片与纸片的透明裁片。渲染保留兄弟图层用于画框变换；不修改模板或用户文档。
- 每叶最多突出两张照片及一个装饰，其余细节在装订时一同贴入。裁片目标位置根据模板变换和共用书脊比例计算，避免独立猜测排版。
- `DiaryOnboardingBook` 持续持有原生 `DiaryPageCurlReader`。页面观察装订状态，未完成页显示背景、已完成页显示成品。悬浮素材独立于纸页裁切层，因此可以伸出纸面；最终纸面保持轻微圆角。
- 翻页完成回调同步当前页、文案和进度。装订完成集合由引导父视图持有，进入风格选择再返回不丢失。
- 每个渲染输出最长边最多 1100 px；处理图层和页面之间让出主线程。只保留渲染结果，不保留用于解码的所有原始图片。

## 验收入口

开发构建使用 `-diary-onboarding -diary-onboarding-page 1` 直接进入引导，页码可选 1、2、3。
`-diary-onboarding -onboarding-verify` 运行三页装订、重复装订调用、进入风格选择与返回的调试检查；结果写入模拟器 App 临时目录 `onboarding-verification.txt`。

回归测试位于 `TravelDiaryTests/Auth/DiaryOnboardingTests.swift`，包含真实资源的六页加载、背景与成品区分、点击前隐藏文字、重复装订、装订期间禁止翻页及返回成品页。
