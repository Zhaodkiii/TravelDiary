# 启动引导的本地手帐播放

## 页面设计
保留奶油白底、黄色品牌标识、深色主按钮和风格选择流程。
前三屏作为同一本六页样册，依次展示龙龛与洱海湖岸、喜洲古镇、周城扎染。首次进入播放照片优先的制作动画，后续展示完整成品。下一步和返回复用原生卷页，皮革外壳固定，内页保持圆角。翻动期间暂时禁用前进与返回，跳过仍然可用。减少动态效果时直接展示成品并关闭卷页。

## 资源来源
大理·把日子过成蓝白色，模板 ID 88a7b289-2c50-49cc-8b53-742e1dcd4360，已发布版本 4。
从后端发布快照获取 OSS 对象，使用预设选页规则生成六页资源包。保留嵌套图层、素材、遮罩和预设格式要求的页面预览。资源体积由 83.3 MiB 降至 33.6 MiB，保留的 143 个文件均核对了文件大小和 SHA-256。
本地包位于 Projects/App/Resources/OnboardingDali.bundle。资源索引为 manifest.json，不在客户端保存 OSS 凭据或临时签名链接。
六页对应原书第 2/3、8/9、16/17 页。引导按清单中的三个阅读单元及其页面 ID 加载。

## 实现
DiaryPresetPackage 读取真实对象与素材，instantiate 创建仅用于预览的内存文档。
DiaryOnboardingPlayback 只加载当前跨页的图片，使用 DiaryCanvasSurface.animateMaterialEntrance 播放。新属性 entrancePhotosFirst 只在引导启用，编辑器原顺序保持默认值。
DiaryOnboardingBook 持续持有 DiaryPageCurlReader，预解码本地六张已发布的大图预览供卷页使用；制作动画作为首次阅读的临时覆盖层，完成后交接同位置的整本阅读器。提前点击会结束制作动画并在短暂收束后翻页。切页不重建阅读器，返回已看页面不重播。原生翻页完成回调同步文案和进度，取消手势保持原页。进入风格选择再返回直接恢复第三跨页。样册读取失败时展示已有成品预览，用户仍能继续。
当前演示表现分层组装过程。源包未记录原作者操作时间线，背景为已完成的背景素材，不能还原真实绘画笔迹。

## 验收
需检查首屏制作动画、提前点击、正反向卷页、手势取消、快速重复点击、减少动态效果、离线启动与风格选择交接。构建和视觉验收结果以实际执行记录为准。

使用 iPhone 18 Pro 模拟器验证三组跨页均能播放到成品。开发构建可传入 `-diary-onboarding -diary-onboarding-page 1` 直接验收首组，页码可选 1、2、3。
预览使用白纸底，仅在源文档没有底色时补上，避免播放起始时出现编辑器透明棋盘格。

## 照片优先的动效优化
左右页全部栅格准备完毕后共同开始。左页面积最大的照片作为主照片，淡入并放大至 1.65 倍，停留后在 2.2 秒内回落；其余照片从 2.5 秒起错开出现。背景在 3.65 秒出现，装饰从 4.1 秒开始，标题和正文在 4.9 秒整段淡入，6.2 秒收尾后保持成品。
同时识别照片绘制类型和模板 photo 语义，覆盖保存为 image 的照片图层。主照片落位时保留一次触感。
