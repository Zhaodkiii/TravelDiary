# 四主题装订引导

引导固定为四页：大理 → 爱情 → 生日 → 亲子。第四页装订完成后按钮为“开始记录”，进入现有首页交接流程；不再附加风格选择页。

## 标准资源

资源包 `TravelDiaryClient/Projects/App/Resources/OnboardingThemes.bundle`，四组跨页来自后台已发布快照：

- 大理·把日子过成蓝白色：龙龛与洱海湖岸。
- 爱情故事：很高兴认识你。
- 岁岁有你：走过照片也走向新一岁。
- 陪你慢慢长大：一只书包。

版本与模板 ID 记录于 `theme-sources.json`。直接从项目 OSS 存储下载选页依赖，共 226 个文件、39,774,074 bytes；逐文件核对大小与 SHA-256，未保存凭据或签名链接。八张原始页尺寸均为 2185 × 3130，保留照片、文字、纸张、装饰和对象关联。

## 视觉与交互

固定一屏，顶部主题标识、中央书本与素材区、底部进度及操作按钮。书本保持原始比例、统一位置与大小，不随装订阶段改变。未完成页只有模板背景，翻页完成后停留 450 ms，再展开素材。

悬浮照片保留轻微倾斜。文字使用模板原始图层，按左右两列及固定行距排列，每叶最多两组，不额外旋转、不添加文字阴影、不展示参考署名。文字高度受独立行高约束，避免长段文字与相邻内容重叠。装饰也使用原始模板素材。

点击装订后，真实照片与装饰落入模板坐标；1.35 s 后显示完整页内文字，480 ms 后显示书下的主题标题及一句说明。装订和翻页时阻止重复操作，跳过保持可用。返回已装订页面恢复成品。

正常进入直接读取 `Playback/index.json` 与预合成图片，不解析模板、不下载 OSS、不在首屏现场绘制。整页用 JPEG，动画裁片用透明 PNG，保持模板坐标与装订分层。进程内复用一次读取的结果，四个主题均立即可用；首次进入直接展开素材，只有翻到未装订页保留 450 ms 的背景停留。预合成包缺失/损坏时才使用 `DiaryPresetPackage` 和 `DiaryPageRenderer` 在内存中重建，不修改模板或用户文档。制作期间手势翻页关闭，下一步通过原生卷页进入背景页。减少动态效果保留装订操作但跳过运动与等待。

开发入口：`-diary-onboarding -diary-onboarding-page 1`，页码为 1–5（第五页为手帐风格选择）。
`-onboarding-verify` 可依次检查四页装订与翻页，日志写入 App 临时目录 `onboarding-verification.txt`。

## 预合成资源维护

`Playback` 约 50 MB，以包体积换掉每次进入的模板解析、原图解码及逐层渲染。它是原始标准模板的渲染产物，不是重新创作的素材。更新模板或渲染规则时必须同步更新：在 Debug 测试中创建 `DiaryOnboardingAssembly(usePreparedPlayback: false)`，调用 `await load()`，再调用 `exportPlayback(to:)` 导出到模拟器临时目录，将产物替换到资源包的 `Playback` 目录。正常生产入口不会执行导出。

`bundledPlaybackIsReadyBeforeAnyAsyncLoading` 验证四个入口无需异步加载便可操作；现有装订回归覆盖背景、照片、文字显现以及已完成跨页的恢复。

## 第五页：手帐风格

顺序为大理、爱情、生日、亲子、手帐风格。亲子装订完成后点击「下一步」进入原有风格选择页。点击风格保存 `diary.onboarding.pendingStyle` 后结束引导，由随记首页接入对应制作流程。五个进度点覆盖全部页面；从风格页返回时恢复亲子装订完成状态。第五页使用项目既有 `TravelStyle-*` 图片，不触发模板合成。
