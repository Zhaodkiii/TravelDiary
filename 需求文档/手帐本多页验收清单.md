## 1. 验收环境与记录

执行时填写：代码提交、应用版本、系统版本、设备型号、剩余存储、照片样本尺寸、初始数据量。现有可用目标设备为用户指定的 Dream 真机；连接状态和系统版本以执行当时读取为准。

每项记录“未执行 / 通过 / 失败 / 阻塞”、实际现象、日志或截图证据。已通过应用编译不等于以下业务场景通过。损坏、断电与磁盘不足模拟只操作隔离测试目录或测试样本，不破坏用户真实手帐。

## 3. 存储、异常与异步场景

| ID | 阶段 | 故障/操作 | 必须验证 |
| --- | --- | --- | --- |
| S01 | A | 新页快照文件写到一半终止测试进程 | book.json 没有发布半成品页，旧有效页仍能打开 |
| S02 | A | 页快照完整，但发布 book.json 前失败 | 当前 revisionID 不变；未发布目录不会当作新页展示 |
| S03 | A | book.json 发布成功，书架摘要写入失败 | 页面仍报告保存成功；重新扫描后摘要恢复 |
| S04 | A | 发布成功后预览生成失败 | 页可编辑，预览显示可重试状态，不重复提交内容 |
| S05 | C | 同一本不同页保存准备交错完成 | 正式目录保留两页最新版本，不发生整本覆盖 |
| S06 | C | 同页基线版本与目录不匹配 | 拒绝覆盖，保留草稿；不误判为已保存 |
| S07 | C | 旧预览任务晚于新版本返回 | 卡片和封面不显示旧版本，新图不被覆盖 |
| S08 | C | 快速滚动造成卡片复用 | 缩略图与 pageID 对应，无串图 |
| S09 | C | 清理全部预览缓存 | 页面与原图完整；能按需重建预览 |
| S10 | C | 损坏 library-index.json | 扫描本目录重建，不清空或删除真实手帐 |
| S11 | C | 损坏 book.json，previous 有效 | 明确提示恢复上次完整目录；不静默承诺最新修改仍在 |
| S12 | C | 某页 JSON/drawing/资源损坏 | 保留原数据，不按空内容保存；其他页仍可读 |
| S13 | C | 存储不足导致写入失败 | 旧发布版本完整，内存编辑保留，失败可重试 |
| S14 | C | 内层对象有草稿时强制结束，再重开 | 正式页未混入草稿；出现匹配基线的恢复/放弃入口 |
| S15 | C | 多层嵌套草稿恢复 | 从外层未提交会话恢复，不把孤立内层内容直接写根页 |
| S16 | C | 取消对象后草稿异步写入晚结束 | 不重新出现已取消的可恢复草稿 |
| S17 | C | A/B 页共用照片，删除 A 并执行回收 | B、保留历史及草稿所需原资源不被删 |
| S18 | C | 预览/读盘进行中切换账号 | 新账号看不到旧本、旧缩略图与旧任务提示 |
| S19 | C | 保存失败时退出登录 | 不绕过未保存失败释放会话，按账户集成规则处理 |
| S20 | C | 页面已软删除时旧任务回调到达 | 不把页面重新加入有效目录 |
| S21 | C | 未知 schemaVersion、循环对象、越界路径 | 拒绝解析/覆盖，错误可理解，文件保持原样 |

## 4. 性能与辅助功能

| ID | 阶段 | 场景 | 验收记录 |
| --- | --- | --- | --- |
| Q01 | C | 20 本×100 页，命中缩略图缓存打开书架与总览 | 首屏可交互时间、峰值内存，不以全部预览完成作为首屏条件 |
| Q02 | C | 单页 30 对象含手机原始照片 | 加载到可编辑时间、峰值内存、原图是否下采样 |
| Q03 | C | 连续浏览 100 页 | 内存不随页数持续线性增长，邻页外的解码缓存可淘汰 |
| Q04 | C | 收到内存压力后返回已浏览页 | 可重建缓存被释放，作品数据仍完整 |
| Q05 | C | 动态字体最大档、VoiceOver、减少动态效果 | 卡片与按钮可操作，页码/封面/失败状态有文字说明，排序有按钮替代 |
| Q06 | C | 冷启动无缓存、冷启动有缓存、热进入 | 分开记录，不能用最优一次代替平均行为 |

性能数值为详细需求中的建议目标，必须由实机记录决定是否达标，不能只凭代码路径判定。
