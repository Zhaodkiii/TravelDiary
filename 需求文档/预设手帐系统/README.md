## 1. 目标、范围与现状

用户已明确：设置专门的预设浏览和预览页面；按徒步、城市、美食等系列组织手帐；可以整本添加到“我的”，也可以选单页新建本或添加到已有本；添加后能继续编辑、替换图片和文字。制作端提供 PSD 批量转换脚本，输出 JSON、分层素材和预览文件。客户端统一加载格式，首版只加载应用内置包，预留云端来源。

界面排列、导入策略和限额属于实施基线，可在原型验证中调整。用户已明确采用“系列 → 预设手帐本 → 页面”的三级关系，不沿用硬编码单页菜单作为长期方案。

当前实现：通用资源包加载器、徒步/城市/美食系列目录、预设浏览与页预览、整本和单页导入、尺寸适配、导入中断恢复和构建期资源校验已接入。现有内置内容为雨崩引言单页包，15 个有效像素图层；其他城市、路线和美食预设须把完成转换的包放入对应资源目录。此 PSD 的图片文字仍不能直接改字。

首版交付：系列分类、预设本列表、预设本详情、逐页预览、整本导入、单页导入、统一包校验和本地加载、制作端转换及审核工具。云端下载、购买订阅、用户发布模板、收藏同步、在线 PSD 解析和自动 OCR 转文字均不在首版范围。

## 2. 分类与内容组织

```text
预设
├── 徒步系列
│   ├── 雨崩（预设本，包含多页）
│   ├── 武功山
│   ├── 太行山
│   ├── 四姑娘山
│   └── 虎跳峡
├── 城市系列
│   ├── 苏州
│   ├── 上海
│   ├── 成都
│   └── 杭州
└── 美食系列
    ├── 地方小吃
    ├── 咖啡与甜点
    ├── 探店记录
    └── 家常料理
```

“系列”是一级分类；上图中的雨崩、武功山、太行山、四姑娘山、虎跳峡、苏州、上海、成都、杭州、地方小吃、咖啡与甜点、探店记录、家常料理，全部直接代表可导入的预设手帐本，不再设置中间主题层。每本包含自己的封面和多页内容。一本归属一个系列，可附多个检索标签；将来增加不同风格版本时，作为同系列内的另一预设本展示。

系列、书本、页面分别使用稳定 ID，名称和排序可修改，文件路径不得由显示名称生成。上述书本纳入预设制作清单，内容制作与校验完成后才进入发布目录，不展示只有名称没有内容的占位本。

预设页可标注角色：封面、引言、路线、每日记录、照片墙、美食、总结、自由页。这只是筛选与说明，不限制编辑。封面通过 pageID 指定，页序独立维护。

## 3. 页面与导航

在现有手帐入口中提供“我的 / 预设”切换，不额外增加一级 App Tab。预设是独立浏览页面，与编辑器状态分开。

### 3.1 预设首页

- 顶部系列切换，下方直接展示该系列的预设手帐本；默认“全部”，保留本次浏览选择及滚动位置。
- 卡片显示封面、名称、系列、页数和风格；检索匹配名称、系列、标签，首版完全离线。
- 搜索无结果可清空筛选；单包损坏只让该包不可用，不使整个目录加载失败。
- 图像按比例展示，透明区域使用棋盘格或中性底板；底板不进入导出。

### 3.2 预设本详情

显示封面、简介、总页数、纸张比例、下载后的资源大小（首版描述为“素材大小”）、编辑能力说明和全部页面缩略图。底部主要动作“整本添加到我的”。

点击缩略图进入全屏逐页预览，左右滑动浏览，有页码、页面标题和“使用这一页”。首版不用仿真翻页动效。预览为只读；只有副本导入成功后进入编辑器。

详情和预览必须说明“可替换照片 X 处、可编辑文字 Y 处”；有图片文字时标注“部分文字为图片装饰”。数量由真实图层能力计算，不由运营手填。

### 3.3 从我的本子进入预设

“新建一页 → 从预设选择”携带目标 bookID 和可选 afterPageID。预设首页仍可浏览整本；单页操作默认加入来源本。整本操作始终新建一本，按钮清楚区分“整本新建”和“本页加入当前本”。返回不丢失原本页面位置。

## 4. 整本与单页使用流程

### 4.1 整本添加

预览本 → 整本添加 → 填写本名（默认模板名）→ 准备与校验 → 创建副本 → 进入新本总览。

- 使用预设本的推荐纸张尺寸，保留页序、指定封面、各页名称和分层。
- 创建新的 bookID、pageID、contentID、layerID；素材按本内去重策略映射，不引用只读模板文件。
- 同名本允许存在；每次主动再次添加产生独立副本。自动重试使用相同 operationID，不能重复生成本子。
- 导入成功显示“已添加 N 页”，提供“编辑第一页”；不自动把用户带进某个内层对象。
- 模板更新、删除或下架都不能改变已经导入的用户作品。

### 4.2 单页使用

预览页 → 使用这一页 → 选择“新建手帐本”或“添加到已有手帐本”。

新建本：默认名称由模板本名和页名组成，用户可改；默认采用该页纸张尺寸，只导入这一页及其依赖资源，作为新本封面。

已有本：选择本子，展示页数与尺寸；默认追加末尾，从特定页面发起时默认插入该页之后。支持在导入前修改插入位置。原封面保持不变；目标为空本时按现有首页面封面规则处理。

选择目标、尺寸适配、确认过程中均不创建占位页；取消不影响作品。首版单页选择，不做任意多页勾选；协议和导入服务接受 pageIDs 数组，为后续多选预留。

### 4.3 尺寸不一致

继续保持一本内统一页面尺寸。整本导入使用模板本推荐尺寸；单页加入已有本时使用目标本尺寸。

默认“等比完整放入并居中”，不拉伸、不裁切。缩放 s=min(目标宽/源宽,目标高/源高)，居中偏移 tx=(目标宽−源宽×s)/2、ty=(目标高−源高×s)/2；适配预览显示留白。用户可返回改选目标本。首版不提供自动裁满。

实现直接适配源根画布：将根画布尺寸改为目标尺寸，对每个根图层的位置应用等比缩放和居中偏移，对其缩放倍率乘以 s；保留图层 ID、层序、可见性、旋转与子对象内部坐标。顶层笔画应用相同变换。不得把整页包装成一个额外的 canvas 对象，否则外层图层面板只显示一层。相同尺寸直接使用源根内容。额外留白默认透明，不把棋盘格变成图片。旧导入页不会自动重写，重新从预设导入即可使用新流程。

### 4.4 导入后的编辑

- 预设与普通作品进入同一个通用编辑器；对象仍通过全屏页面独立处理。
- 照片替换保留外框、位置、尺寸、角度及装饰；默认 cover 重新取景，不沿用不适合新照片的旧偏移。
- 真文字保留文本、排版和可用字体属性；修改超长文本不得悄悄裁掉，提供溢出提示并允许调整文本框。
- 图片文字仅可移动、缩放、隐藏、删除或整图替换；若要“改字”，需制作端提供真正的文字层版本。
- 默认装饰可锁定防误触，用户可解锁；模板锁定不是永久禁止编辑的权限。
- 替换图片、修改文字、对象编辑、涂鸦沿用现有撤销机制；整本/页面导入不伪装成页内的一次撤销，删除通过本子管理完成。

## 5. 导入事务与异常处理

导入服务负责 staging → validated → publishing → committed；状态和 operationID 写入日志。取消只在发布之前生效，发布后以成功结果返回，删除由用户正常操作。

整本：在 staging 准备完整本目录，资源及所有页面通过验证后再发布到书架。单页：先完成依赖素材和页面快照，再原子更新现有 book.json。发布之前任何失败均不在“我的”显示半本或坏页。

单页发布前比较目标目录 catalogRevision；发生并发新增、删除、排序时重新读取，重新确定插入位置，避免覆盖其他更新。指定锚点已删除时提示用户重新选位置，不能盲目按旧下标插入。

失败或崩溃后根据操作日志和发布结果恢复：已提交返回同一结果，未提交清理或续做；禁止仅凭超时判定失败后重新创建。清理只删除本操作未被正式作品引用的文件，共享素材不得误删。

导入前核算源文件复制、暂存、页面 JSON 与缓存的空间需求，预留可配置余量；空间不足给出可理解提示。进度按已处理字节/页面显示，按钮防连点。切到后台时完成安全检查点；重开仍保持一致，不要求一定在后台完成。

账号切换期间已启动操作继续绑定原 ownerID，结果不得出现在另一个账号书架；浏览内置模板可共用，个人作品目录按既有账号作用域隔离。

## 6. 制作与内容治理

每个模板本必须有封面、全部页缩略图、逐页大预览、明确页序、源 PSD 对照和编辑能力报告。展示预览必须由转换后的项目数据生成或经同一渲染规则验证，不可直接用未经校对的 PSD 成品图代替。

模板来源、作者、素材授权和字体使用方式由制作端记录；字体不能随便复制进包。没有分发许可的字体只能按审核结果使用可分发替代字体或栅格化，同时说明文字编辑能力变化。

示例照片、旅行文案均作为示例内容；替换照片不应删除照片上独立的标题或装饰。模板页不得夹带用户私有照片路径、账号信息或开发机器绝对路径。

## 7. 后续云端边界

首版只实现 Bundle 来源，不展示下载、登录云服务或网络失败流程。资源提供者返回完整、已验证的本地只读包位置后，统一加载器才开始工作。

后续云端提供者负责下载、断点续传、真实性验证、缓存与离线可用性；格式校验、浏览、导入复制及编辑流程共用。来源和格式版本是两个独立概念；不得为云端另造图层格式。

模板版本不可变，新增版本使用新的 packageVersion；副本保留来源版本用于追踪，绝不自动覆盖用户修改。撤下模板只影响未来浏览下载，不影响已导入作品。

## 8. 实施顺序和完成标准

1. 固定统一包 Schema、制作映射与测试样本，雨崩引言作为首个真实样本。
2. 完成可复用离线转换、包校验和转换报告；退出硬编码图层坐标。
3. 完成 Bundle 提供者、统一加载器、只读预览。
4. 完成系列分类/预设本/页面预览界面。
5. 完成整本与单页导入事务、ID 重映射和尺寸适配。
6. 验收保存重开、独立对象编辑、异常中断、离线使用和资源独立性。

首个验收本需至少两页，不能以只有雨崩引言一页作为整本能力验证。其他路线名称可配置，但只有素材和审核完成后才能发布。

## 9. 页面状态与补充交互

| 页面或动作 | 状态及处理 |
| --- | --- |
| 分类首页 | 加载中、有效目录、空分类、目录不可读；错误状态支持重试 |
| 预设详情 | 元数据成功但预览失败时显示占位和重试；核心图层/资源校验失败时禁用导入并说明原因 |
| 逐页预览 | 当前页优先加载，相邻页预读；返回详情定位到原页 |
| 目标本选择 | 展示可写且属于当前账号的本；没有本时直接提供新建入口 |
| 导入进行中 | 显示阶段和数量；页面关闭时保留操作状态，重复打开看到同一任务 |
| 导入成功 | 跳转目标本并定位新增页面；整本导入定位新本总览 |
| 导入失败 | 保留模板选择和用户输入；仅在核实未提交时提供重新执行 |

对同一个预设连续主动使用允许重复，按钮“已添加过”只能作为提示不能永久禁用。用户离开预览不自动保存一份副本。导入标题、页标题、模板名称分别保存，用户重命名不会改动模板目录。

支持 VoiceOver 读出卡片名称、系列、页数和当前页码；小屏与大字体下详情按钮不能遮住页面缩略图，导入目标选择不能只依赖颜色区分。页面预览只读手势与编辑器手势分开，避免滑动翻页时误触编辑。

## 11. 项目初始资源与打包规则

用户已明确：上述预设本后续整理到项目初始资源目录，随应用构建一起打包。开发制作流程为：PSD 原文件 → 批量转换与校验 → 各本 JSON、分层素材、预览 → 用户移动单本包到 iOS 对应系列目录 → 整个 DiaryPresets.bundle 纳入应用资源 → 启动自动扫描生成展示目录。新增或修改内置本时更新资源包并重新构建发布，不在手机首次启动时解析 PSD。

应用启动后台扫描系列目录内各本 package.json；打开预设页面时按需加载封面和页面，不把全部预设本复制到“我的”。只有用户主动整本或单页添加时才生成可写作品副本；应用内置资源始终只读。完整制作产物必须随构建保留目录关系，不能只打包预览或遗漏图层 JSON。

构建前扫描系列目录，校验每本的版本、封面、页面、对象及素材均存在；构建后检查应用包内目录和资源可读性。未完成本不移动到 iOS 发布资源目录；目录内的本若缺资源应使资源校验失败，不能静默生成残缺应用包。首次安装与升级均使用应用随包目录，升级不覆盖用户已导入的作品。

工具位置与搬运方式已明确：离线工具独立位于 `/Users/dream/Documents/project/TravelDiary/PSD转换工具`；用户将生成的单本 `.diarypreset` 目录包移入 iOS 的 `DiaryPresets.bundle/城市系列/` 等对应目录。已有系列新增本无需改 Swift 或总目录 JSON，重新编译安装后启动自动展示。具体目录与命令见 [PSD 批量转换与验收](./02-PSD批量转换与验收.md)。本次更新为需求修订，工具与自动发现逻辑仍待实现。
