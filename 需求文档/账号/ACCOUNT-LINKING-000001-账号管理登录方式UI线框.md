# ACCOUNT-LINKING-000001 账号管理登录方式 UI 线框

创建日期：2026-07-15  
文档类型：plain text UI wireframe  
关联工单：`ACCOUNT-LINKING-000001-账号管理登录方式绑定与修改客户端需求工单.md`

## 1. 范围

本文只描述客户端新增 UI 内容，不描述服务端实现。

新增 UI 包括：

1. 账号管理页新增“登录方式”区块。
2. 绑定手机号、邮箱、Apple 的流程弹层。
3. 修改手机号、邮箱的流程弹层。
4. 已有方式安全认证。
5. 目标手机号/邮箱 OTP 验证。
6. Apple 绑定与 Apple 再认证。
7. 成功、失败、冲突、ticket 过期状态。

## 3. 登录方式区块

### 3.1 三种方式全部展示

服务端返回三种 provider，客户端固定展示三行。

```text
登录方式
┌────────────────────────────────────────┐
│  [phone]  手机号                       │
│           未绑定               绑定 >  │
├────────────────────────────────────────┤
│  [mail]   邮箱                         │
│           ab***c@example.com    修改 > │
├────────────────────────────────────────┤
│  [apple]  Apple ID                     │
│           已绑定                       │
└────────────────────────────────────────┘
```

注意：

```text
账号资料邮箱 User.email 不是邮箱登录方式。
邮箱登录方式只看 provider=email 的 SocialIdentity。
```

因此可能出现：

```text
账号信息
┌────────────────────────────────────────┐
│  资料邮箱       apple_mail@example.com  │
└────────────────────────────────────────┘

登录方式
┌────────────────────────────────────────┐
│  [mail]   邮箱                         │
│           未绑定                绑定 > │
└────────────────────────────────────────┘
```

这表示 Apple 登录曾写入资料邮箱，但用户还没有主动绑定邮箱登录。

### 3.2 全部未绑定时

理论上正常登录账号至少有一种登录方式。若服务端返回全部未绑定，客户端展示异常态，不允许进入绑定。

```text
登录方式
┌────────────────────────────────────────┐
│  当前账号暂无可用登录方式               │
│  请重新登录后再试                       │
└────────────────────────────────────────┘
```

### 3.3 操作规则

```text
┌──────────┬──────────┬──────────────┬──────────────┐
│ provider │ 未绑定   │ 已绑定        │ 操作          │
├──────────┼──────────┼──────────────┼──────────────┤
│ phone    │ 绑定     │ 修改          │ 支持绑定/修改 │
│ email    │ 绑定     │ 修改          │ 支持绑定/修改 │
│ apple    │ 绑定     │ 仅展示已绑定   │ 不支持修改解绑 │
└──────────┴──────────┴──────────────┴──────────────┘
```

## 4. 绑定流程总览

```text
点击绑定
   │
   ▼
选择已有方式认证
   │
   ├─ 手机号 OTP
   ├─ 邮箱 OTP
   └─ Apple 再认证
   │
   ▼
服务端返回 verification_ticket
   │
   ▼
目标方式验证
   │
   ├─ 绑定手机号：输入手机号 -> 发送 OTP -> 输入验证码
   ├─ 绑定邮箱：输入邮箱 -> 发送 OTP -> 输入验证码
   └─ 绑定 Apple：Sign in with Apple
   │
   ▼
提交绑定
   │
   ├─ 成功：刷新登录方式列表
   └─ 失败：停留当前步骤展示错误
```

### 13.4 Apple 修改入口不存在

Apple 已绑定时不展示任何修改按钮。

```text
登录方式
┌────────────────────────────────────────┐
│  [apple]  Apple ID                     │
│           已绑定                       │

```

### 13.5 Apple email 不等于邮箱已绑定

Apple 登录后服务端可能返回资料邮箱，但登录方式仍以 `provider=email` 为准。

```text
账号信息
┌────────────────────────────────────────┐
│  资料邮箱       97621528@qq.com         │
└────────────────────────────────────────┘

登录方式
┌────────────────────────────────────────┐
│  [mail]   邮箱                         │
│           未绑定                绑定 > │
├────────────────────────────────────────┤
│  [apple]  Apple ID                     │
│           已绑定                       │
└────────────────────────────────────────┘
```

用户必须点击“绑定”并完成邮箱 OTP 后，邮箱才成为登录方式。

如果异常调用修改接口后服务端返回 `apple_identity_change_not_supported`：

```text
┌────────────────────────────────────────┐
│             暂不支持                    │
│  Apple 登录暂不支持修改。                │
│                                        │
│                         [知道了]       │
└────────────────────────────────────────┘
```
