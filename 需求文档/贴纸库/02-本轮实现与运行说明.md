# 贴纸库与背景库：运行与发布

2026-10-17。代码位于 `material_library`；当前已在本地 MySQL 执行迁移，未部署线上 API。

## 服务端

使用项目虚拟环境执行 `python manage.py migrate`。新增 `/api/v1/materials/` 接口：

- `categories/`：统一分类及中文子类。
- `libraries/?type=sticker|background&template=<UUID>&template_version=<版本>`：库列表；`favorites=1` 过滤收藏库。
- `libraries/<UUID>/items/?version=1&q=便条&kind=paper&subcategory=note&after=0`：固定版本分页。
- `items/?type=sticker&q=花草&scope=libraries&favorites=1`：跨库搜索；scope=libraries 限定收藏库，favorites=1 限定收藏单张；共享素材去重。
- `libraries/<UUID>/favorite/`、`items/<UUID>/favorite/`：POST JSON `{"favorite":true}`，取消传 false；返回当前收藏人数和本人状态。
- `revisions/<整数>/download/`：POST，返回 15 分钟有效的 OSS URL、SHA-256 和字节数，API 不返回图片字节。
- `manage/<模板UUID>/`：管理员查看和提交库成员、分类、关键词、别名及顺序；提交必须携带期望的库 version，防止覆盖他人修改。

统计以收藏关系表 COUNT 为准，不维护容易漂移的重复计数。账号注销通过外键级联清理。库版本与素材 revision 不可变，新发布切换 current；移除成员不物理删除共享资源。

## 转换与入库

使用 PSD转换工具的 `workflow.py publish ... --execute`：在同一数据库事务内发布预设、贴纸库和背景库。资源上传从工作站直达 OSS，失败可能留下可复用资源，不会出现半提交数据库记录。不要在低带宽 API 机器运行上传任务。

给已发布模板补素材库：

```
python manage.py publish_material_library /绝对路径/手帐.diarypreset --template 模板UUID
python manage.py publish_material_library /绝对路径/手帐.diarypreset --template 模板UUID --publish
```

默认 dry-run。`--overrides` 提供图层 ID → include/identity/name/kind/subcategory/keywords/aliases 映射。保持 identity 稳定。工具检查源图像哈希属于当前模板、资源格式/尺寸、分类和透明条件；背景不要求透明。重复内容复用 `blobs/sha256/<哈希>`，相同输入重复发布返回同一库版本。

后台入口：预设手帐 → 选中手帐 → 贴纸与背景库。支持编辑、排序、移除、从全局已发布素材中加入，校验后发布；新文件使用上述受控发布工具上传，不经后台服务器转发。没有人工审核环节。

## iOS

画布“贴纸”打开云端库，包含发现、我的库、当前手帐和内置入口。原有内置收藏/最近使用继续读取相同账号偏好键。模板预览提供贴纸库与背景库入口。单张与整库可以分别收藏。

搜索支持库内、全部库、收藏单张及分类/子分类筛选。目录分页、网格懒加载；缩略图按哈希缓存。原图点击后才下载，共用 PresetDownloadManager 的哈希锁、缓存、分段续传及签名刷新。暂停保留完整分段，继续可复用；关闭面板后重新选择同素材仍可复用完整分段。任务暂停状态本身不跨页面保存。

同一图像在作品内采用稳定资源 ID；重复添加生成独立图层。背景作为带可选标记的锁定底层保存，兼容现有文档渲染；支持完整显示/填满、确认替换、撤销恢复。临时预览是面板内素材预览，尚不是画布实时叠加预览。

- Django 系统检查、迁移一致性检查通过；6 项接口/发布/收藏测试通过。
- iOS 模拟器构建通过；后台 Vue/TypeScript 构建通过。新增 2 项画布测试独立运行通过（资源去重、背景替换撤销）。既有测试目标存在网络/其他旧测试编译错误，本次仅通过命令行排除旧测试完成独立验证，没有修改旧测试；不能据此宣称全量测试通过。
- 本地 MySQL 实际接口检查通过：库列表、24 张贴纸、11 张背景、管理员手帐两库查询。
- 上海已在本地数据库登记：24 张贴纸、11 张背景，均为库 v1；重复发布不增加版本。
- OSS 原图复用已有哈希对象，生成独立缩略图；验证了 OSS HEAD 与登记大小一致。

当前实现不包含：浏览器新文件直传及云端可信校验、收藏离线修改队列、搜索相关性加权/拼音、完整离线库下载、实时画布背景预览、贴纸下载任务列表的跨启动恢复。目录缓存仅对可识别的网络连接错误回退，缓存不是服务端授权的替代。

部署顺序：后端代码与迁移 → 后台静态资源 → 目标数据库发布素材库 → iOS。不要只上线客户端，否则旧 API 会返回 404。生产仍须遵守 TravelDiary 仅发布到 39.106.39.110、禁止发布到 139.196.215.51 的项目约束。
