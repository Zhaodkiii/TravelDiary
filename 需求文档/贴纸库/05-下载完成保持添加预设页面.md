# 下载完成保持添加预设页面

2026-10-18。

问题：整本资源下载完成后，正在显示的“添加预设”sheet 消失，返回模板预览。

原因：列表监听下载可用索引，下载完成会刷新父视图。原 destination 在每次刷新时调用 completeCachedPackage，缓存由无变有后，返回的视图从 RemotePresetReaderDestination 变为 DiaryPresetReaderDestination。原云端预览页及其 selection 状态被销毁，所承载的 sheet 也随之关闭。

修复：destination 始终返回 DiaryStablePresetDestination；该视图通过 StateObject 持有 PresetReaderPresentation，在首次打开时冻结本地/云端来源与模板版本。后续下载进度与可用索引变化不替换当前 reader。退出后重新打开会建立新的 presentation，此时可优先使用完整本地缓存。

导入流程继续使用既有 downloadOnly 下载任务；资源完成后仅进入 ready，更新 readyPackage 并启用添加。确认导入成功后才执行 completed 回调；取消仍由用户操作决定。

回归场景：打开尚未缓存的模板 → 显示添加 sheet → 整本资源就绪 → 当前 reader 保持云端身份 → 资源可供确认添加；再次进入模板时可使用本地缓存。PresetDownloadPerformanceTests 新增该状态切换验证，并检查缓存准备不会自动产生导入结果。

验证：iOS Simulator arm64 应用构建通过（BUILD SUCCEEDED）；新增回归测试及相关测试目标完成编译，但模拟器安装应用时因系统盘空间不足（NSPOSIXErrorDomain 28）失败，测试未实际运行，不能计为通过。未清理用户数据或修改模拟器配置。
