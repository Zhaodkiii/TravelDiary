# 02 坐标与照片编辑

## 1. 下次打开如何找到同一个位置

假设页面是 1000 × 1400。照片组合的中心保存为页面坐标 (500,600)，手机显示页面多大都不修改这两个数。下次打开，先恢复页面，再恢复组坐标，最后把整页等比显示到屏幕。

例如查看比例 0.3，页面左上角在屏幕 (20,80)，页面点 (500,600) 显示在 `(20+500×0.3, 80+600×0.3)=(170,260)`。换一部手机时只重算查看比例和页的屏幕偏移。

需要保存的是：页面尺寸、父子关系、每个节点的变换、本地尺寸、照片裁剪。最后选中哪个元素、用户把页面放大几倍，不影响作品恢复。

## 2. 位置、锚点、尺寸分别表示什么

| 属性 | 例子 | 解释 |
| --- | --- | --- |
| size | 400 × 300 | 照片外框在本地的尺寸 |
| pivot | (200,150) | 本地框中心，旋转缩放围绕它发生 |
| position | (500,600) | pivot 在父坐标中的位置 |
| scale | 1.5 | 整个对象放大 1.5 倍 |
| rotationDegrees | 30 | 顺时针转 30° |
| flipX / flipY | false / false | 独立翻转标记 |

设计坐标左上为原点，x 向右、y 向下。先把本地点减去 pivot，再缩放与翻转，再旋转，最后加 position。矩阵采用列向量：

```text
M = T(position) × R(angle) × S(scale × flip) × T(-pivot)
世界矩阵 = 父世界矩阵 × 当前矩阵
屏幕坐标 = 查看矩阵 × 世界矩阵 × 本地点
```

导出时将查看矩阵换为输出比例；输出 2000 × 2800 对应 1000 × 1400 页面时，比例为 2。

## 3. 分组和子图层的位置关系

示例照片本地 400 × 300，照片在组内的 position=(200,150)、pivot=(200,150)，所以照片子图层的矩阵是单位矩阵，左上仍为组坐标 (0,0)。

组 pivot=(200,150)、position=(500,600)、scale=1、角度 0°，照片左上在页面为 (300,450)，右下为 (700,750)。

贴纸 size=100×100、pivot=(50,50)、position=(380,0)，它在组内左上为 (330,-50)，一部分伸出照片上沿。映射到页面后左上为 (630,400)。负的组内坐标合法，不应夹取回照片范围。

组移动到 (550,620) 后，每个子元素页面位置都增加 (50,20)，但文件中只改组 position，贴纸和照片自己的数据保持原值。

## 4. 大小和方向改变后如何保存

### 4.1 整体缩放与旋转

将上例组合 scale 改为 1.5，照片旋转前的边长成为 600 × 450。组中心仍在 (500,600)，照片左上成为 (200,375)。如果再旋转 90°，该左上角围绕中心转到 (725,300)。旋转后的轴对齐包围框不等于原始 size，不能用包围框宽高反写照片尺寸。

子层自身也有缩放和旋转：无翻转时，子层有效倍率为祖先与自身 scale 的乘积，角度为沿路径的角度和；有翻转时不能简单累加角度，始终以矩阵合成为准。

### 4.2 改照片框比例

裁剪框从 400×300 改成 400×400 属于本地布局变化，不是整体 scale。保持原来的框中心在父级位置不变，更新 size 和中心 pivot，重新计算 cover 及合法 offset。原型照片 pivot 为中心，因此保留 position 即可；如果以后支持非中心 pivot，应先算旧中心在父级的位置，再反求新 position。

组 pivot 保持固定，旁边贴纸不自动重新贴边。若希望装饰始终钉在照片右上角，需要未来新增锚定约束；当前模型只表达固定相对坐标，不能默认推断吸附关系。

### 4.3 仅缩放查看

用户双指放大页面不修改任何图层 scale；否则保存后作品自身会被意外放大。

## 5. 框内图片取景

外框规定展示范围，crop 决定框中看到原图哪部分。原图保持不变。

```text
base = max(框宽 / 原图宽, 框高 / 原图高)
图片显示倍率 = base × zoom
显示宽 = 原图宽 × 图片显示倍率
显示高 = 原图高 × 图片显示倍率
图片左上 x = (框宽 - 显示宽) / 2 + offsetX
图片左上 y = (框高 - 显示高) / 2 + offsetY
```

zoom ≥ 1。offset 使用照片框本地单位，并限制：

```text
|offsetX| ≤ (显示宽 - 框宽) / 2
|offsetY| ≤ (显示高 - 框高) / 2
```

例：原图 4000×3000，框 400×300，zoom=1.5，则 base=0.1，显示为 600×450。offset=(-30,20)，图片左上=(-130,-55)，偏移合法范围 x=±100、y=±75。

下次打开按同一公式重建位置，使用低清预览时仍依据原图尺寸计算几何，再将预览映射到同一显示矩形；不能直接把低清图像素宽高当作新的文档尺寸。

## 6. 照片每次操作修改哪些字段

| 操作 | 持久化变化 |
| --- | --- |
| 页面拖动照片组合 | 组 transform.position |
| 进入组合后移动照片 | 照片 transform.position |
| 整体放大组合 | 组 transform.scale |
| 单独转动照片 | 照片 transform.rotationDegrees |
| 框内移动取景 | crop.offsetX/Y |
| 框内放大图片 | crop.zoom 及 offset |
| 替换照片 | assetId，crop 重置 cover 居中；外框、组布局不变 |
| 修改框比例 | size、pivot/position 补偿和 crop |

所有动作开始时保存 before，结束时生成 after，一次手势对应一条命令。取消操作恢复 before；撤销也触发新的保存修订。图片编辑不会依赖“记住上一次手指滑了多少”，只需要最终完整状态即可恢复。
