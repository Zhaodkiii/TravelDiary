# 03 图层关系与贴纸文字

## 1. 两种关系分开表达

**归属由嵌套决定，遮挡由数组顺序决定。**元素的文件名、创建时间和 ID 都不决定层级。

```text
page.layers（从底到顶）
├── 照片组合 A
│   └── children（从底到顶）
│       ├── 照片
│       ├── 胶带贴纸
│       └── 日期文字
├── 页面独立贴纸
└── 页面标题
```

组内日期盖在胶带上；页面标题盖在整个组合上。页面贴纸不能夹在组内照片和日期之间，它只能放在整个组合之前或之后。若需要位于组内两层之间，就应在组内创建该元素。

渲染顺序为背景 → 每个页面元素及其完整子树 → 页面画笔。组透明度先合成整组再应用，不把组内交叉区域重复减淡。

## 2. 添加贴纸

### 在页面添加

1. 获取并持久保存贴纸资源，记录 assetId。
2. 创建 image 图层，role=sticker，crop=null。
3. size 按素材原始比例初始化，pivot 为中心。
4. position 使用页面设计坐标。
5. 把新图层追加到 page.layers，成为普通内容最上层。

### 在照片组合中添加

前四步相同，但 position 使用组合本地坐标，追加到该组合 children。通过当前父矩阵的逆变换，把屏幕点击点转换成正确本地坐标。不能把页面中心坐标原样写成组内坐标。

完成后存档与组合关系为：图层 id 唯一、素材 assetId 可共享、父级通过 children 推导。再次打开后，程序遍历同一 children，自然恢复跟随移动的关系。

## 3. 修改层级、隐藏和锁定

数组 `[照片, 贴纸, 文字]` 中贴纸上移一层，保存为 `[照片, 文字, 贴纸]`。置底移动到当前父级数组开头，不跨父级；隐藏、锁定不改变数组顺序。

- visible=false：不显示不导出，数据保留。
- locked=true：照常显示和导出，不能通过画布拖动；面板可解锁。
- 隐藏或锁定组影响整个子树；不覆盖子层自己保存的状态。
- 删除贴纸删除的是图层引用，不立即删除资源文件。
- 复制贴纸生成新 layerId，可复用 assetId；两个图层位置独立。
- 用户从图层面板选择对象时使用 layerId 定位，不依赖数组索引作为身份。

首版不开放跨组拖动和解组。后续若增加，必须使用 `新本地矩阵 = inverse(新父世界矩阵) × 旧世界矩阵` 保持视觉位置；同时保留局部尺寸、取景和资源。不能只换 parent 而保留原 position。

## 4. 添加与编辑文字

文字需要保存可编辑字符串，示例：

```json
{
  "text": "今天在海边\n晴天，微风",
  "layoutWidth": 360,
  "fontId": "app.default.regular.v1",
  "fontSize": 28,
  "lineHeightMultiple": 1.2,
  "alignment": "center",
  "color": "#333333FF"
}
```

文字位置和方向使用与图片相同的 transform。首版文字 pivot 为文本框顶部中心；宽 360 时 pivot=(180,0)。输入更多行只改变推导高度，顶部位置不变。

| 操作 | 改变什么 | 结果 |
| --- | --- | --- |
| 修改内容 | text | 重新计算换行和高度 |
| 修改字号 | fontSize | 字体真实尺寸变化，重新排版 |
| 调整文本框宽 | layoutWidth，必要锚点补偿 | 换行改变，不拉伸字形 |
| 整体放大文字 | transform.scale | 已排版内容整体等比缩放 |
| 旋转文字 | rotationDegrees | 排版不变，整体转动 |
| 移动组合 | 组 position | 组内文字跟随 |

例如修改文本宽度后，将顶部中心 pivot 更新到新宽度的一半并保留 position，可保持文本框顶部中心在父级中的位置。不要根据新的文本高度自动把整段文字重新居中到照片。

打开文档时解析 fontId，按保存的样式重新排版。原型 app.default.regular.v1 由应用字体注册表解析；该标识不能指向每次随机选择的字体。跨系统版本的默认字体可能变化，严格可复现输出需要固定字体文件及布局版本。应用随附字体以稳定版本管理，文档自带字体需记录资源引用和授权允许的文件副本。

## 5. 画笔与上述关系

画笔不属于普通 layers 或 children；page.drawingRef 指向整页绘画数据。它不跟随照片，不受普通置顶影响。保存的是可恢复绘画数据，不能只保存一张透明 PNG，否则会丢失原生绘画编辑能力。导出时才转换成与整页对齐的图像并覆盖到内容上。
