# 05 完整示例与操作对照

## 1. 文件入口

本目录提供一组彼此引用一致的结构示例：

- [CURRENT.json](./示例文档/CURRENT.json)
- [manifest.json](./示例文档/revisions/r000001/manifest.json)
- [页面 JSON](./示例文档/revisions/r000001/pages/20000000-0000-4000-8000-000000000001.json)

**这些文件用于阅读协议，不是可导入的成品包。**两张示例图片未提供，byteSize 和 sha256 为 null 标明待替换；生产文档必须写入实际数值和校验值并验证资源存在。画笔为 null，表示示例尚未绘画。

## 2. 示例画面

页面 1000×1400。照片组合 pivot=(200,150)、position=(500,600)，无旋转缩放。组内照片为 400×300；贴纸 100×100 位于组内中心 (380,0)；文字顶部中心位于组内 (200,320)。页面还有一个独立标题。

```text
页面图层顺序
0 照片组合
  0 照片：页面左上 (300,450)，框为 400×300
  1 贴纸：页面左上 (630,400)，尺寸 100×100
  2 文字：页面顶部中心 (500,770)，排版宽 360
1 页面标题：顶部中心 (500,100)
顶层画笔：空
```

照片 crop 为 zoom=1.5、offset=(-30,20)。照片框位置仍是 (300,450)，只是框中原图内容改变。

## 3. 编辑动作和落盘字段

| 用户动作 | 当前页 JSON 的改变 | 重开结果 |
| --- | --- | --- |
| 把照片组合右移 50、下移 20 | layers[0].transform.position=(550,620) | 照片、贴纸、组内文字一起移动 |
| 把组合放大 1.2 倍 | layers[0].transform.scale=1.2 | 所属内容与间距一起放大 |
| 组合顺时针旋转 15° | layers[0].transform.rotationDegrees=15 | 子元素围绕固定组 pivot 转动 |
| 把贴纸拖到照片左上 | children[1].transform.position=(20,0) | 只变贴纸；照片不移动 |
| 让贴纸盖住组内文字 | children 数组改为照片、文字、贴纸 | 绘制顺序改变，ID 不变 |
| 修改说明文字 | 相应 text payload.text 改变 | 重新排版，仍是可编辑文字 |
| 把组内文字字号改为 32 | payload.fontSize=32 | 字体变大并按原宽度换行 |
| 替换照片 | photo.assetId 指向新资源，crop 重置 | 外框和装饰仍保持原布局 |
| 添加一笔 | 写入新的 drawing blob，page.drawingRef 更新 | 笔画按页面坐标盖在上方 |

上表的数组下标仅帮助理解这份样例。实际命令使用稳定 layerId 查找对象，因为调整层级后数组下标会变化。

## 4. 一次重开应该确认什么

1. CURRENT 和 manifest 文档 ID、revision 相符。
2. pageRefs 指向页面文件，页面 id 相符。
3. 所有 layerId 唯一；图层树和数组顺序保持原样。
4. assetId 都可从资源表解析；生产素材文件可解码且校验一致。
5. 组 position=(500,600)，不会被新的设备宽度覆盖。
6. 照片 size、crop 与组 transform 分别恢复，没有重复计算缩放。
7. 贴纸能越出照片外框；组内文字和页面标题归属正确。
8. 文本宽度、字体、字号决定换行；不使用上次屏幕截图代替文字。

若用户完成了表中的操作，则按更新后的值确认，而不是强制恢复本示例初始值。
