必须保持的六条约定：

1. 页面有固定设计尺寸，位置不依赖手机屏幕大小。
2. 子图层坐标相对父分组；最外层相对页面。
3. 同级数组顺序从底到顶；不额外保存另一份 zIndex。
4. 图片文件通过 assetId 引用；移动、裁剪不覆盖源图。
5. 完成照片组合编辑仍保留照片、贴纸、文字子图层。
6. 文档、素材和画笔数据持久保存；缩略图与查看比例不能作为作品恢复依据。

`示例文档` 中的 JSON 为结构样例，引用的图片没有随包提供，因此不是可以直接导入的完整作品。生产数据应使用真实文件大小、校验值和字体资源。
