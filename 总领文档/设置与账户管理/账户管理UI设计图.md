# 账户管理 UI 设计图

## 一、文档定位

本文档是 `账户管理需求.md` 的 UI 设计补充，使用 plain text Markdown 还原用户提供的 7 张账户管理截图。本文只描述截图中已经出现的页面、弹窗、按钮、输入框和用户可见状态，不补画截图外未出现的界面。

截图对应关系：

| 编号 | 截图状态 | 对应功能 |
| --- | --- | --- |
| UI-01 | 账户管理顶部与账号信息 | 资料展示、登录方式列表首屏 |
| UI-02 | 账户管理中下部 | 登录方式列表、退出登录、危险操作 |
| UI-03 | 手机号绑定成功弹窗 | 绑定/修改成功反馈 |
| UI-04 | OTP 错误弹窗 | 验证码错误反馈 |
| UI-05 | 验证新登录方式 OTP | 目标手机号验证码输入 |
| UI-06 | 绑定手机号输入 | 新手机号输入与发送验证码 |
| UI-07 | 确认注销账户 | 注销最终确认 |

代码位置：

- 主页面：`SupportClient/SupportClient/Projects/Features/AccountManagement/Presentation/AccountManagementView.swift`
- 状态编排：`SupportClient/SupportClient/Projects/Features/AccountManagement/Presentation/AccountManagementViewModel.swift`
- UI 组件：`SupportClient/SupportClient/Projects/Features/AccountManagement/Presentation/Components/AccountManagementComponents.swift`
- 设置入口：`SupportClient/SupportClient/Projects/Features/Settings/Presentation/SettingsView.swift`
- 主 Tab 与路由：`SupportClient/SupportClient/Projects/App/Sources/App/AppCoordinatorView.swift`

### 7.2 元素与功能标注

| 元素 | 显示内容 | 功能说明 | 交互 |
| --- | --- | --- | --- |
| 错误弹窗标题 | `操作失败` | 通用错误标题 | 无 |
| 错误说明 | `验证码错误，请重新输入` | 后端或本地校验失败原因 | 无 |
| 好的按钮 | `好的` | 关闭错误弹窗 | 点击后回到 OTP 输入层 |

### 7.3 错误后状态要求

- 错误弹窗关闭后不退出绑定流程。
- 应清空或允许重新输入 OTP。
- 倒计时继续运行。
- 目标手机号仍保持冻结，不因错误而允许直接编辑。
